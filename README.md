# Instapro

MVP социальной сети для обмена фотографиями.

## Реализованная функциональность:
- Авторизация и регистрация пользователей.
- Просмотр общей ленты постов.
- Просмотр ленты постов конкретного пользователя.
- Добавление нового поста (с загрузкой изображения).
- Постановка и снятие лайков с постов (с поддержкой сохранения в браузере).
- Форматирование даты публикации (например, "5 минут назад").

20 часов

## Фактически затраченное время
